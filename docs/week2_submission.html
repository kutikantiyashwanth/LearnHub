3. Design Choices & Branding

Color Palette

TokenColorHexUsage
PrimaryIndigo#4F46E5Buttons, active states, headings
AccentTeal#14B8A6Success states, gradient end, checkmarks
BackgroundLight Gray#F7F8FCApp background
SurfaceWhite#FFFFFFCards, inputs
Text PrimaryDark Slate#1E293BHeadings, body text
StarAmber#FBBF24Rating stars

Typography & Spacing

  • Font: Segoe UI / System default — clean and readable on all platforms
  • Heading sizes: 28px (screen titles), 22px (greetings), 18px (section titles)
  • Consistent spacing tokens: xs=4, sm=8, md=16, lg=24, xl=32, xxl=48
  • Border radii: sm=10, md=14, lg=20, xl=28 — progressively rounded cards

Responsive Layout

  • Mobile (<600px): Single column, bottom navigation bar
  • Tablet (600–1023px): 2-column grid for program cards
  • Desktop (>1023px): Split layouts (brand panel + form on Login/Signup), sidebar-style detail
